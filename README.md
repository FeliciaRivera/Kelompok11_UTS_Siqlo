# Kelompok 11 - UTS Siqlo (Struk Uniqlo)

Program CLI (Command Line Interface) yang mensimulasikan mesin kasir
untuk menghasilkan struk belanja, dengan studi kasus toko Uniqlo yang kami ubah menjadi **Siqlo**.

## Fitur Utama

1. **Baca katalog barang dari file** — `src/barang.txt`
2. **Pilih barang secara interaktif** — kasir memasukkan nomor barang satu per satu
3. **Pilih metode pembayaran** — Tunai atau Non-Tunai (Kartu)
4. **Perhitungan otomatis** — subtotal, diskon, total, PPN (Tax Inclusive), dan kembalian
5. **Cetak struk** — ditampilkan ke terminal dan jendela JFrame 
6. **Simpan riwayat transaksi** — hasil struk disimpan ke `src/struk_output.txt` (mode append)
